# Avaliação Certa · site do serviço

Página estática do serviço de respostas às avaliações do Google. Publicada em **https://avaliacoes.paulojr.dev.br** via GitHub Pages.

## Arquivos
- `index.html`, `style.css`, `script.js`: página principal (demonstração interativa incluída)
- `tema.js`: modo escuro compartilhado por todas as páginas (lembra a escolha e respeita o tema do aparelho)
- `privacidade.html`: política de privacidade (exigida na verificação do app OAuth do Google)
- `404.html`: página de erro do GitHub Pages
- `img/social-preview.png`: imagem de compartilhamento (1200×630)
- `CNAME`: domínio personalizado

## Configuração
Tudo que muda fica no topo de `script.js` (`CONFIG`): nome do serviço, WhatsApp, e-mail e `API_URL`.
Também troque o nome manualmente em `<title>`, nas tags `og:` e em `privacidade.html`/`404.html`.
